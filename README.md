# 科技行业从业者心理健康求助行为分析 (OSMI Survey)

## 📌 项目背景
本研究使用 Kaggle 上的 OSMI 科技行业心理健康调查数据（N=1251），探讨影响从业者是否寻求心理治疗的核心因素。

## 🛠️ 数据清洗与方法
- **数据清洗**：剔除了年龄异常值（<18岁或>75岁）；使用正则表达式将 40 多种乱码的性别数据（如 "M", "Cis Male", "Enby"）归类为 Male, Female, Other 三类。
- **缺失值处理**：将 `work_interfere` 等变量的缺失值保留为独立类别 "Unknown"，避免信息丢失。
- **统计方法**：描述性统计（Table 1）、Wilcoxon 秩和检验、多因素 Logistic 回归、VIF 共线性诊断、ROC/AUC 模型评估。

## 🔍 核心发现
- **工作干扰**是极强的预测因子：工作经常受心理问题干扰者，寻求治疗的几率是从不受干扰者的 **30 倍**（OR=30.0, 95% CI: 16.0-58.5）。
- **性别差异**：控制其他变量后，男性寻求心理治疗的几率显著低于女性（OR=0.50）。
- **家族史**：有家族史者寻求治疗几率是无家族史者的 2.62 倍。
